# 🍳 WhatToEat

## Про проєкт

WhatToEat — це вебзастосунок, який допомагає користувачам вирішити, що приготувати з продуктів, які вже є вдома.

Застосунок використовує штучний інтелект для створення простих рецептів відповідно до наявних продуктів та обраної категорії страви.

## Проблема

Часто люди не знають, що приготувати з продуктів, які є в холодильнику. Через це вони витрачають багато часу на пошук рецептів або купують зайві продукти.

## Рішення

WhatToEat допомагає швидко знайти ідею для страви. Користувач вводить наявні продукти, обирає категорію, а штучний інтелект створює рецепт.

## Основні функції (MVP)

1. Введення продуктів — користувач вказує продукти, які має вдома.
2. Вибір категорії страви — сніданок, обід, вечеря або десерт.
3. Генерація рецепта — штучний інтелект створює рецепт на основі введених продуктів та обраної категорії.

## Використані технології

- Python — мова програмування.
- Streamlit — створення вебінтерфейсу.
- OpenRouter API — підключення штучного інтелекту.
- Requests — надсилання запитів до API.
- Python-dotenv — зберігання API-ключа в окремому файлі .env.

## Як запустити проєкт

1. Завантажити або скопіювати репозиторій на комп'ютер.
2. Встановити необхідні бібліотеки:

   ```bash
   pip install -r requirements.txt
   ```

3. Створити файл .env у головній папці проєкту.
4. Додати до нього свій API-ключ:

   ```text
   OPENROUTER_API_KEY=ваш_ключ
   ```

5. Запустити застосунок командою:

   ```bash
   python -m streamlit run app.py
   ```

6. Відкрити посилання, яке з'явиться в терміналі.
